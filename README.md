 🐧 Aprende Linux desde Cero

Libro interactivo para **niños y jóvenes de El Salvador 🇸🇻**  
Basado en **Jupyter Book**, con notebooks interactivos y versiones en PDF.

## 🎯 Objetivo
Enseñar Linux de forma:
- Clara
- Práctica
- Visual
- Progresiva

## 👥 Público
- Niños (8–12 años)
- Jóvenes (13–17 años)
- Docentes y centros comunitarios

## 📘 Contenido
- Computadora y Linux
- Archivos y carpetas
- Terminal
- Permisos
- Python básico
- Internet y software libre

## ⚙️ Requisitos
- Linux (Ubuntu, Pop!_OS, Mint)
- Python 3.9+
- Jupyter Book
